# 人类学思想史 · HISTORY OF ANTHROPOLOGY
### summarized & visualized — 观点、人物与争论的可视化地图

模仿 **denizcemonduygu.com/philo**（History of Philosophy）的组织方式搭建的人类学平台：
一张可自由浏览的"思想地图"，把人物、观点以及观点之间的**继承/同意**与**批评/分歧**关系
放进同一个画布里。

**线上地址：<https://joey-builder.github.io/anthropology-map/>**

本地也可以直接用浏览器打开 `index.html`（双击即可，纯静态、无需联网）。
上线与绑定自有域名的步骤见 [`DEPLOY.md`](DEPLOY.md)。

## 功能

- **观点时间线**（主视图）：横轴为年份，按 10 个领域分行。**观点文字本身画在画布上**，
  每条 = 人名 + 领域色点 + 一句话观点，纵向按缩放级别贪心分行，所以每个点旁边就写着这个人的主要观点。
  缩放分三级放出文字：1 级＝每位学者 1 条代表作，2 级＝全部要点，3 级＝全部观点。
  关系曲线**按类型分侧**：继承/同意一律向下鼓、批评/分歧一律向上鼓，两类线各自成束；
  默认细而浅，**悬停某句话时只有与它相关的连线亮起**，其余淡出。
- **人物时间线**：每位学者一行，按出生年排序；圆点是他/她在某一年提出的观点。
- **人物图谱**：人物按关系强度自动布局，可看出学派、师承与论战结构。
- **田野地图**：实心圆 = 田野点（大小 = 学者数），空心圆 = 机构城市，
  曲线从学者主要任教/研究机构所在地连向田野点——二十世纪人类学"从大都市到田野"的结构一目了然。
  点击田野点或城市，可以查看对应的学者清单。
- **观点索引**：按人物分组列出全部观点（含关系说明与原文题名），可一键"聚焦"或"定位"回时间线，
  并可下载 Markdown 版全文索引，适合当作阅读与写作时的检索入口。
- **筛选**：领域、时期、关系类型三类药丸。单击某领域/时期＝**只看这一个**（其余的点直接消失），
  再点一次恢复全部，Shift/⌘ 点击可多选；"入门"只保留 20 位核心人物，
  "要点"只保留每位学者 2–3 条代表性观点（**默认开启**，关掉可看全部 347 条），
  "文字"开关画布上的观点文字（关掉后只剩纯圆点时间线）。
- **搜索**：人物、观点、关键词、年份皆可搜；点击结果自动聚焦并居中。
- **详情抽屉**：人物简介、关键词、全部观点（年份 / 中文题名 / 原文题名 / 领域）及其关系说明，
  关系可点击跳转；每条观点带"引用"按钮，人物页可"复制此人文献 / 导出 BibTeX"。
- **面向研究的导出**：关于面板里可一键导出全部数据（JSON）、全部文献（BibTeX）、
  观点表（CSV，Excel 可直接打开）。
- **其他**：深色模式、缩放/适应屏幕、链接可分享（地址栏会记录筛选与聚焦状态，如
  `#view=pg&cats=religion&basics=1`）。

## 数据说明

当前版本收录 **90 位学者、347 条观点**（其中 **184 条**标为各人的代表性要点）、
**323 组跨学者关联**（另有 117 组同一学者内部的承接，只在详情与索引里显示）、
**89 个田野点 / 研究区域**，覆盖古典进化论到
当代本体论转向、多物种研究、数字人类学与医学人类学，并包含费孝通、林耀华、阎云翔、王铭铭、
项飙、景军、庄孔韶等中国研究。观点年份取著作/论文的初版年；生年不易确证者标"约"。

`js/meta.js` 提供每条观点的**原文题名**，可直接用于检索与文献导出；导出的是编者整理的
二次文献信息（作者、年份、题名），**正式引用前请核对原书版本与页码**。

## 如何增改内容

只改 `js/data.js` 即可，结构如下：

```js
{
  id:"boas", name:"弗朗茨·博厄斯", en:"Franz Boas",
  born:1858, died:1942, country:"美国（德裔）", period:"found",   // period 见文件顶部 periods
  branches:["theory","language","biological"],                    // 领域，见 branches
  regions:["北美西北海岸"], tags:["文化相对主义"],
  summary:"……",
  statements:[
    { id:"boas-relativism", year:1911, branch:"theory", work:"《原始人的心智》",
      text:"观点原文（中文）……",
      links:[{ to:"morgan-stages", type:"disagree", note:"关系说明" }] }
  ]
}
```

规则：

- 新增领域/时期：在文件顶部的 `branches` / `periods` 里加一项（含颜色），
  人物与观点的 `branch`、`period` 引用其 `id` 即可，筛选药丸会自动生成。
- `links` 只需在**一侧**写一次，两个方向都会生效；`type` 取 `"agree"` 或 `"disagree"`。
- `to` 指向任一观点的 `id`；写错会有控制台提示（页面照常运行，只是忽略该条）。
- 入口人物放在 `starter` 数组里。
- 新增人物时要在地图上出现：在 `js/meta.js` 里补 `homes`（所在城市）与 `sites`（田野点）坐标，
  以及该人物各条观点的原文题名（`works`）。没有田野点的学者留空数组即可。
